参考 Seedmux 的 space 切换器：符号、单色、当前项是一枚白圆

为什么不是字母头像

  • 机器不是人，字母块会读成一排 App 图标；10 台时像调色板。缩写还会撞（mac-mini / mac-mini-2）。
  • Seedmux 的 space 条是纯符号 + 单色，当前项用白圆和染色图标说“你在这”。安静，但位置记得住。
  • 每台机器给一个类型图标（笔记本 / 主机 / 服务器 / 芯片 / 终端 / 云），比两个字母更有信息量。

状态只留一个点

需要你 失败

4px，只标“要你处理”的机器；数字不挂在图标上，全部留给底部计数器。上一版每个头像都挂数字，是噪音的来源。

身份放在哪

  • 机器名只在标题出现一次：term-fleet / carls-Mac-mini（Seedmux 的 space 名也在标题）；状态栏与悬浮提示作兜底。
  • 列表里不再有“机器 → tabs”的分组；顶部标签只属于当前机器，标签上不需要机器 pill。
  • 状态栏仍给完整 host / 平台 / 会话数，作为兜底。

切换的规则

  • 点符号 = 整个工作区切换；每台机器各自记住“打开过的标签 / 当前标签”，切回来原样恢复。
  • 只淡入 200ms，不做横移——横移会让人以为同时在看多台机器。
  • 侧栏折叠：坞变成窗口底部的浮条（就是 Seedmux 那条 bar 的位置），切换不会丢。
  • 计数默认全舰队；点数字跨机器跳到下一条对应会话，⌘J 直接跳到“需要你”。

还没拍板

  • 计数口径：全舰队（收件箱）vs 本机（= 当前机器）。两个都做会重复吗？
  • 列表与标签：侧栏列全部会话、顶部列已打开标签，是否让列表只留“未打开的会话”？
  • 排序：固定顺序保住肌肉记忆，还是“需要你”优先？我倾向前者 + 一个点。
  • 空机器 / 离线机器：仍在坞里占一个位置（现在 pi-4、macbook-air 就是这样），位置不跳。
  • 折叠态浮条：要不要也带机器名？现在只有符号 + 计数。
