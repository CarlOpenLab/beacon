# 侧栏：只管你正在用的那几台

Carl 说「设备都展示出来很干扰视线」。真实情况是：装了中继之后名单只增不减，七八台机器里每天用的两台，其余每台都占一行标题，还各带一个 0 的计数和一个 `+`。一行标题 28 高，五台就是 140——左栏在 268 里，五分之一给了永远不点的地方。

这篇只解决「哪些机器占常驻位置」，不动会话行、不动状态语言。

---

## 1. 什么算「其他」

一台机器归到「其他」，当且仅当同时满足：

- 这个窗口里它没有任何会话（`entriesFor(id)` 为空）；
- 它没有正在「需要你」的会话（waiting / error）；
- 它不是当前选中的那台。

有一条不满足，它就是一台正常机器，占自己的位置。

「需要你」排在「没会话」前面是故意的：一台机器没会话但有一条在等你回答，那是这个产品最该喊出来的事，不能因为「它平常很安静」被我收起来。

## 2. 「其他 N 台」那一行

位置：所有正常机器之后、页脚「需要你」之前。

| 件 | 值 |
| --- | --- |
| 行高 | 28（和机器标题同高，但它不是标题） |
| 内距 | 左 10、右 8（和会话行同一套） |
| 箭头 | 11px `TextFaint`，收起时朝右、展开时朝下，和机器标题那颗同一套旋转 |
| 字 | 12 medium `ink2`：「其他 3 台」 |
| 计数 | 不再重复写一遍数字，就那一个 N |
| hover | `RowHover` 40% 底、圆角 6（和标题一致） |

N 为 0 时整行不画。

点一下展开：收起来的机器按原样长在**这一行下面**，各自是正常的机器标题（圆点、名字、0 计数、`+`）。再点收回。展开状态只在这一次打开窗口期间有效，不写盘——它是「看一眼」，不是配置。

## 3. 右键收起来

机器标题的右键菜单加一项：**`在侧栏里收起这台机器`**。选了就把它从侧栏整个拿掉——不进「其他」，不占任何位置。选择写进本地配置，重启还在。

拿掉之后它去哪了：设置里有一节「侧栏 · 机器」，列出认识的每一台，前面一个开关。关掉的就是收起的。默认全部打开。

**一条例外（Ato 2026-10-26 定）：** 一台被收起的机器只要有会话变成「需要你」，它照样回到侧栏，按正常的等待/报错样式出现。理由和当初否掉「按状态自动折叠」是同一条：可以安静，不能瞒着不说。

**它是有来有回的**：那件「需要你」的事过去之后（会话被回答、结束、或者不再等待），这台机器在 1.5 秒后自己收回隐藏。那 1.5 秒是留给手指的——用户刚点完它，行不能在他指针底下消失。没有这一半，一次等待就把一台亲手收起的机器永久放回来，设置里那个开关就成了骗人的，侧栏也会越用越长。

## 4. 设置里的那一节

```
侧栏
  机器
    ● mac-mini          [开]
    ● 办公室那台         [开]
    ○ 旧笔记本           [关]
      收起的机器不在侧栏显示；有会话需要你时会自动出现。
```

- 行高 44，左侧一个 7px 状态点（和侧栏里那颗同一个颜色语言），名字 13，右侧开关。
- 那一行说明一直显示，不要藏进 tooltip——它是这条规则的唯一解释。
- 一台机器都没被收起时，这一节仍然显示（否则用户不知道该功能存在）。

## 5. 空状态

全部机器都被收起或都在「其他」里、而「其他」又收着的时候，侧栏只剩会话为空的状态行：

- 有「需要你」的：照常显示那些会话。
- 一台都没有：第一行「没有显示的机器」13 `TextMuted`，不可点；第二行是**能点的入口**——「在设置里可以选回来」13 medium `ink`，右侧一颗 11 `chevron.right` `TextFaint`，行高 44，点了直接落到设置的「侧栏 · 机器」那一节。

  第二行不做成纯说明文字：它是唯一告诉你「还有救」的一句话，却要用户自己去找设置，那和这几天一直在删的死胡同是同一类。

## 6. 不动的地方

- 会话行、状态环、租赁胶囊、关闭与刷新的悬停规则。
- 机器标题自己的那个箭头（收起这台机器的会话）——它管的是会话，第 3 节管的是整台机器，两个开关不合并。
- 页脚计数：收起的机器里的会话仍然计入「需要你」，这和第 3 节的例外是同一件事。

## 7. 验收

1. 六台机器、只有两台有会话 → 侧栏是两台正常机器 + 「其他 4 台」；点开看到四行，再点收回。
2. 把一台没会话但有 waiting 的机器放进来 → 它不归「其他」，正常占一行。
3. 右键收起一台有会话的机器 → 它从侧栏消失（连会话一起），设置里那个开关变成关。
4. 被收起的那台来一条 waiting → 它自己回到侧栏；把那条回答掉 → 1.5 秒后它自己收回去。
5. 全部收起 → 看到那两行；点第二行直接到设置的「侧栏 · 机器」。
6. 重启 app → 收起的选择还在，「其他」回到收起状态。
