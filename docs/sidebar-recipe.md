# 侧栏：一行里只留一个状态

桌面端左栏「有点小乱」，乱的不是间距，是**每一行有几个同级标记**。268 宽的栏里，一条会话行行尾常驻「只读」胶囊 + 状态环 + 关闭按钮三件东西，机器标题里又常驻刷新和 +。眼睛每扫一行都要处理三个同级的符号，扫到第三行就放弃了。

这篇只讲改哪几处、改成什么值，不改结构。

---

## 1. 会话行：行尾只留状态环（`cmd/tfdesktop/nav.go`）

| | 现在 | 改成 |
| --- | --- | --- |
| 名字 | 13.5 `Text` | 不变 |
| 租赁胶囊（只读 / 已退出 / 创建中） | 每行都画（`badgeChip`） | **只在当前选中的那一行画**；其余行用状态环颜色 + 名字 `TextMuted` 表达 |
| 状态环 | 常驻 14 | 不变（这是要一眼扫的东西） |
| 关闭 ✕ | 常驻 20 | **只在悬停时出现**（`row.Hovered()`），右键菜单里的关闭不变 |

理由：胶囊和状态环说的是同一件事，一个胶囊吃 34–44pt，正好是名字被截断的那几个字；关闭是破坏性操作，不该站在阅读路径上等误触。

`paneRow` 同样处理：胶囊只在 `selected` 时画。

## 2. 机器标题：让它比里面的东西重（`cmd/tfdesktop/sidebar.go`）

| 元素 | 现在 | 改成 |
| --- | --- | --- |
| 标题 | 12.5 semibold `TextMuted` | 12.5 semibold **`Text`** |
| 计数 | 12.5 `TextFaint` | **11** `TextFaint`，`FontFeatures("tnum")` |
| 刷新 | 常驻 20 | **悬停出现**（+ 右键菜单保留） |
| + | 常驻 20 | 不变（常用操作） |

理由：现在分组比它装的东西还轻（标题 muted、会话名 `Text`），层级是反的。刷新当年留在常驻的理由是「列表看着旧时立刻点得到」，这条也适用于关闭按钮，而关闭更危险——两者一起改成悬停，行为才一致。

## 3. 分组之间：一条线，不是一片空

现在两组之间是 18pt 空白（`Margin(top,0,3,0)`），滚动时分不清「下一台机器」和「这台机器的下一个会话」。

- 组间：`14` 上边距 + `0.5pt` `Divider` 横线（左右各留 8 内距），只有前一组有会话时才画。
- 组内第一条会话与标题的间距保持现状。

## 4. 页脚：只留「需要你」（`sidebarFooter`）

三个计数（需要你 / 进行中 / 已完成）在 268 宽的底栏里互相抢。只有橙色那个是要动手的：

- 常驻只画 `waiting`。
- `working` / `done` 进 hover 的 tooltip，`waiting+working+done == 0` 时照旧显示机器数与在线点。

---

## 不动的部分

行高 34、分屏行 30、选中行的白胶囊与阴影、悬停底色、状态环的形状语言、拖拽换序时那个洞、pane 的虚线树枝、左右栏折叠动画——都对，这次一个都不碰。

## 验收

在一台有三台机器、十来条会话的窗口里看：

1. 眯眼扫一遍左栏，能不能在不停顿的情况下分出「机器」和「会话」两层。
2. 有没有任何一行同时出现两个以上的行尾标记（除当前选中那行）。
3. 关闭按钮只在指针压上去时出现，且位置不随着出现而把名字推走（用绝对定位或预留 20pt 空白，名字不能跳）。
