01为什么

终端应该跟着人走。

不是又一层远程桌面。Beacon 让同一组真实 shell 同时存在于三个客户端里，并且始终知道谁在写入。

  1. 01 / DETACH

    断开，不是结束。

    锁屏、合盖、Wi-Fi 闪断只是客户端离开。进程和 PTY 留在主机，重连时按字节偏移续上，不重放、不丢失。

    环形缓冲 · 增量续接
  2. 02 / LEASE

    一个 shell，一个写入者。

    一个 PTY 只有一条 stdin。纪元租约保证同一时刻只有一个控制端，其余客户端实时镜像，接管是一次明确的动作。

    纪元租约 · 一键接管
  3. 03 / OUTBOUND

    机器出门，不开门。

    受控机器主动外联中继，不需要公网 IP、入站端口或 VPN。中继只配对字节流，不接触 PTY，也不接触密钥。

    出站 WSS · 0 入站端口

04上手

三条命令，一支舰队。

从源码构建，或直接取 Release 里的二进制。自包含，没有运行时依赖。

  1. 01
    起一个守护进程

    tfd 持有 PTY，默认监听 127.0.0.1:7678。

  2. 02
    把中继放到公网

    可选。tfrelay 只做流配对与鉴权，不持有任何 shell。

  3. 03
    打开窗口或浏览器

    tfdesktop 和 Web 客户端附着到同一批会话。

完整部署手册 
# 从源码构建（Go + pnpm）
git clone https://github.com/CarlOpenLab/beacon.git
cd term-fleet && pnpm run build

# 起守护进程：真实 PTY，走一条 WebSocket
./bin/tfd

# → http://127.0.0.1:7678
# 公网中继：只配对字节流
./bin/tfrelay -addr 127.0.0.1:7698 -devices devices.json

# 受控机器主动外联，不开入站端口
./bin/tfd -relay wss://relay.example.com/relay/agent
